
# CPF-Misturas-Betuminosas

Gestão de fabrico de misturas betuminosas.

## ⚠️ Aviso importante

**Alterei a localização!**

Utiliza este link e pede ao Flávio o teu novo "ID" e "Palavra-Passe":
👉 https://cpf-misturas-betuminosas.pages.dev

Este repositório GitHub é mantido apenas como cópia de segurança/arquivo do
código-fonte. Os ficheiros aqui presentes podem estar **desatualizados** em
relação à versão publicada.

### Como atualizar o site

Não é através deste repositório. As atualizações são feitas diretamente no
painel do Cloudflare Pages, arrastando a pasta com os ficheiros atualizados:

👉 https://dash.cloudflare.com/?to=/:account/pages/view/cpf-misturas-betuminosas

### Dados

Os dados da aplicação (diárias, clientes, fórmulas, utilizadores, etc.) estão
guardados no **Firebase (Firestore)**, projeto `cpf-scrpn` — não neste
repositório.
